# Portal logo

Portal (2007) logotype by Valve, sourced from Wikimedia Commons:
https://commons.wikimedia.org/wiki/File:Portal_Logo.svg

Original SVG: https://upload.wikimedia.org/wikipedia/commons/d/df/Portal_Logo.svg

The source identifies the logo as public-domain text/simple geometry, with trademark rights retained. The original SVG is stored unchanged. `portal-ring.svg` extracts only its blue ring path for the model-switch button; CSS displays a white version in dark mode.
